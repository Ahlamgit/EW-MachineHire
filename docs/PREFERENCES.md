# EW Machine Hire — Project preferences

Living project constraints from the stakeholder. Prefer these over conveniences that imply recurring spend.

**Status legend:** **Confirmed** (stakeholder-directed) | **Proposed** | **Open**

---

## Confirmed

### Zero ongoing service fees for the new app (2026-11-04)

EW Machine Hire must operate with **zero ongoing service fees**.

| In scope (must stay $0) | Out of scope (existing spend OK) |
|-------------------------|----------------------------------|
| App hosting | Existing company website hosting |
| Database | Existing domain registration/renewal |
| Auth | Existing company email (e.g. Titan) |
| File storage | |
| Bandwidth / egress | |
| Notifications delivery | |
| Supporting cloud services required to run the app | |

**Rules**

- No paid subscriptions as the long-term solution.
- No paid overages as the long-term solution.
- No temporary trials as the long-term solution.
- Do **not** purchase plans, credits, domains, or add-ons on behalf of the project.
- Prefer vendors that **stop or restrict** when free limits are reached rather than auto-charging.
- Do **not** promise that any third-party free tier will remain free forever; re-check terms before claiming ongoing fitness.
